# agentchute v1.5.4

This patch release makes blocked turn-end verdicts visible to the wrappers that read stderr, and makes installs and updates actually finish the job: hooks, enrollment blocks, and the spec now refresh reliably across real version boundaries, with CI rehearsing the whole path on every PR. Protocol v2.5 and registration wire version `v: 3` are unchanged.

- Blocked `turn-end`/`gate` verdicts are mirrored to stderr in text and `--json` modes, ending the content-free Stop-hook re-prompt loop on stderr-channel wrappers ([#124](https://github.com/agentchute/agentchute/pull/124)).
- `install.sh` refuses a non-interactive upgrade-in-place that would skip setup, and warns on PATH shadowing after install ([#128](https://github.com/agentchute/agentchute/pull/128)).
- `update` repairs hooks before the failure-prone setup phases and defers lease invalidation until the resync succeeds; `--no-resync` names what stays stale ([#130](https://github.com/agentchute/agentchute/pull/130)).
- `AGENTCHUTE.md` auto-refreshes on resync via a version marker ([#131](https://github.com/agentchute/agentchute/pull/131)); the `ac` dispatcher exports `AGENTCHUTE_BIN` ([#126](https://github.com/agentchute/agentchute/pull/126)); `serve` self-heals the launched wrapper's hook ([#129](https://github.com/agentchute/agentchute/pull/129)).
- `doctor` exact-compares every installed hook and blocks on binary version splits across dispatcher/PATH/running executable ([#127](https://github.com/agentchute/agentchute/pull/127)); init planners refuse symlinked targets ([#132](https://github.com/agentchute/agentchute/pull/132)).
- CI rehearses a real old-to-current `update` with a stale hook and legacy spec on every PR ([#133](https://github.com/agentchute/agentchute/pull/133)).
