# agentchute v1.6.0

**In progress.** This file accumulates notes until the M6 release; it is not a published release.

## Operation seam (M1)

**The seam is an internal refactor only.** No behavior change, no new command, no new flag, and no hub capability in this material. There is nothing to do on any lane for the seam itself: no fleet cutover, no forced update, no re-run of `setup`. Protocol v2.5, registration wire version `v: 3`, and the enrollment marker are all unchanged.

Every user-visible surface of the seam is byte-identical to v1.5.7: the same commands, the same text and `--json` output, the same exit codes, the same hook contracts. The seam itself is a boundary moved inside the binary.

- Each coordination operation — `send`, `check`, `ack`, `gate`, `status`, `register`, the runner's tick, and owed-ledger cleanup — moved out of `internal/cli` into a new `internal/op` package, behind a request/response shape per operation. `internal/cli` keeps the flag parsing, the terminal rendering, and the process concerns, and calls the op layer for the work. `internal/loop` is untouched: zero-byte diff ([#148](https://github.com/agentchute/agentchute/pull/148)).
- The dependency direction is one-way and enforced by a test that parses the package's own imports rather than by convention: `internal/op` must not import `internal/cli`. That constraint is the point of the release — an operation that cannot reach into the CLI is an operation that can later be driven by something other than a local terminal ([#148](https://github.com/agentchute/agentchute/pull/148)).
- Display-only code stayed in `internal/cli`, and streamed output is now delivered as events the caller renders, so an operation no longer writes to a stream directly. Where a helper moved, a thin alias or adapter stayed behind under its old name and signature, which is why the existing test suite passes essentially unmodified: three test files needed one edit site each — a reassigned package-level variable's set/restore pair in two of them, one struct literal in the third — plus an import line, and only because a struct literal and a reassigned package-level variable cannot be aliased ([#148](https://github.com/agentchute/agentchute/pull/148)).
- 77 test cases cover the op layer directly; the full suite is 849 passing cases, plus one skipped. Both counts include subtests, count `pass` events only, and are reproducible at `7d08654` with `go test -count=1 -json ./...`.

## Upgrading

Nothing is required for the seam itself. The wire and the filesystem layout did not change in this material. Further notes accumulate here until the M6 release.
