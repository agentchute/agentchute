# agentchute v1.5.6

This patch release makes `agentchute update` self-contained: it repairs its own bookkeeping, narrates its one silent phase, and no-ops cleanly when there is nothing to do. Protocol v2.5 and registration wire version `v: 3` are unchanged.

- Wrapper-membership self-heal: saved state predating wrapper recording (`"wrappers": null`) with hook files installed gets membership adopted and recorded directly in `setup.json` — no more NOTE prescribing a manual `agentchute setup --wrappers <list>` follow-up. Every current setup run records a non-nil wrapper list (explicit `--wrappers none` and zero-detection `--wrappers all` both record `[]`), so a recorded choice is never overridden by hook files installed outside membership ([#138](https://github.com/agentchute/agentchute/pull/138)).
- `Downloading <tag> (<asset>)...` is printed before the download, which previously produced no output and read as a hang ([#138](https://github.com/agentchute/agentchute/pull/138)).
- An ambient `agentchute update` already on the latest release reports "already up to date" and stops instead of silently re-downloading the same asset and fencing the fleet for a no-op; explicit `--version <current>` still forces the full reinstall ([#138](https://github.com/agentchute/agentchute/pull/138)).
